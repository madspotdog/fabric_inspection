面料智能检测仪 —— 指示灯说明
====================================

一、三颗指示灯
设备上有三颗指示灯，从左到右依次为：第 1 颗、第 2 颗、第 3 颗。

二、开机 / 待机状态：走马灯
通电开机后，三颗指示灯会依次循环点亮（第 1 颗 → 第 2 颗 → 第 3 颗 → 第 2 颗 → ……，来回流动），
这种"走马灯"表示：设备已经就绪，可以开始检测。
此时把面料样品放到镜头下，按键即可检测。

三、检测结果：只亮一颗
每次检测完成后，只点亮其中一颗灯，表示这次判定的档位
（屏幕右上角同时显示"判定档位 第 N 档"，两者一致）：

    只亮 第 1 颗  →  第 1 档  →  其他
    只亮 第 2 颗  →  第 2 档  →  羊毛 / 涤纶 / 低棉
    只亮 第 3 颗  →  第 3 档  →  棉

四、异常状态：闪烁
如果三颗指示灯同时快速闪亮 3 次，表示设备出现异常，
请重启设备，或联系维护人员。

五、操作步骤
    1. 通电开机，等指示灯开始"走马灯"（说明已就绪）；
    2. 把面料样品放好，对准镜头；
    3. 按机身按钮（或用键盘空格键）进行检测；
    4. 看指示灯（或屏幕上的"判定档位"）读取结果。

六、补充说明
    - 指示灯与屏幕显示始终一致；
    - 每次检测需要约 1～2 秒，完成后指示灯会立即给出结果；
    - 开机时请耐心等待指示灯亮起（系统启动需要一点时间）。
