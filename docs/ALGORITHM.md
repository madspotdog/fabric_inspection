# 算法说明

软件名称：纯面料及混纺双模型智能识别软件  
版本：V1.0.0

## 1. 算法目标

输入一张 USB 显微镜采集的面料图像，输出：

- 棉含量档位：低棉 / 中棉 / 高棉（或待定）
- 纯面料类型：棉 / 羊毛 / 涤纶 / 丝 / 亚麻 / 其他
- （过程版本）交叉校验结论：通过 / 复核

> 说明：最终交付版统一输出**判定档位（第 1/2/3 档）+ 三颗指示灯**；
> “通过 / 复核”是开发过程中的中间指标，用于算法验证，不作为最终界面主结果。

算法不直接测量化学成分百分比。三档标签来自训练数据的区间约定。

## 2. 输入与预处理

### 2.1 中心 ROI

设输入图像为 `I(x, y)`，尺寸 `H×W×3`，取中心正方形：

```text
S = min(H, W, 660)
x0 = (W - S) // 2
y0 = (H - S) // 2
R = I[y0:y0+S, x0:x0+S]
```

固定 660 像素的原因是训练和早期实机验证都使用该视场，能减少尺度漂移。

### 2.2 缩放

```text
棉含量模型：R -> 384×384
纯面料模型：R -> 288×288
```

缩放使用双线性/区域插值。训练阶段使用双三次插值，部署阶段受 NCNN 限制使用双线性，二者存在轻微差异，换镜头后需要重新核对。

### 2.3 归一化

棉含量模型（ImageNet）：

```text
x_rgb = RGB / 255
x_norm = (x_rgb - [0.485, 0.456, 0.406]) / [0.229, 0.224, 0.225]
```

纯面料模型：

```text
x_norm = RGB / 255
```

### 2.4 清晰度

使用灰度图拉普拉斯方差：

```text
g = 0.299R + 0.587G + 0.114B
L = [[0,1,0],[1,-4,1],[0,1,0]] 与 g 卷积
focus = Var(L)
```

`focus < 75` 视为对焦偏软，强制输出“复核”。

## 3. 模型

### 3.1 棉含量模型

```text
结构：ConvNeXt-Nano (convnext_nano.in12k_ft_in1k)
输入：384×384×3
输出：3 类 logits [Tier0_Low, Tier1_Mid, Tier2_High]
参数量：约 14.95M
```

### 3.2 纯面料模型

```text
结构：YOLOv8n-cls
输入：288×288×3
输出：6 类 logits [丝, 亚麻, 其他, 棉, 涤纶, 羊毛]
参数量：约 1.44M
```

业务映射：

```text
棉 -> 纯棉
羊毛 -> 纯羊毛
涤纶 -> 纯涤纶
丝 / 亚麻 / 其他 -> 其他
```

## 4. 概率计算

对 logits 做数值稳定 softmax：

```text
m = max(z_i)
p_i = exp(z_i - m) / sum_j exp(z_j - m)
```

如果模型输出本身已经是概率，则只做归一化。

## 5. 级联门控

设纯面料模型输出的“棉”类概率为 `p_cotton`，门限为 `G`（默认 0.20）：

```text
p_cotton >= G  -> 运行棉含量模型
p_cotton <  G  -> 跳过棉含量模型，输出“不适用”
```

门控使用概率而不是硬分类，是为了避免低棉/混纺被纯面料模型误判为“其他”时直接漏掉棉含量识别。

## 6. 档位判定

设棉含量模型概率为 `q = [q0, q1, q2]`，最高概率 `q_max`，次高概率 `q_second`：

```text
tier = argmax(q)
margin = q_max - q_second
```

可信条件：

```text
q_max >= C  且  margin >= M
```

不满足时输出“待定”，不强行归入低/中/高棉。

默认值：

| 参数 | 64 位包 | 32 位包 |
|---|---:|---:|
| 棉门控 G | 0.20 | 0.20 |
| 棉含量置信度 C | 0.46 | 0.55 |
| 棉含量边界 M | 0.00 | 0.10 |
| 纯面料置信度 F | 0.50 | 0.50 |
| 清晰度阈值 | 75 | 75 |
| 清晰度强制复核 | 否 | 是 |

## 7. 交叉校验

设棉含量档位为 `T`，纯面料业务类为 `F`：

```text
通过 = (T == 低棉 且 F == 其他)
    或 (T == 高棉 且 F == 纯棉)
```

完整真值表：

| 棉含量 | 纯面料 | 结论 |
|---|---|---|
| 低棉 | 其他 | 通过 |
| 低棉 | 纯棉/纯羊毛/纯涤纶 | 复核 |
| 中棉 | 任意 | 复核 |
| 高棉 | 纯棉 | 通过 |
| 高棉 | 其他/纯羊毛/纯涤纶 | 复核 |
| 待定 | 任意 | 复核 |
| 不适用 | 任意 | 复核 |
| 任意 | 置信度不足 | 复核 |
| 任意 | focus < 75 且开启强制复核 | 复核 |

交叉校验只能发现“两个模型不一致”，不能在无真值的情况下判断哪个模型正确。

## 8. 可选 TTA

部署默认关闭。评估时可对 0/90/180/270 度分别推理后取平均：

```text
p_final = (p_0 + p_90 + p_180 + p_270) / 4
```

在固定盲测上：

| 方式 | 单图 | 推理成本 |
|---|---:|---:|
| 单帧 | 67.50% | 1× |
| 四向 TTA | 73.75% | 约 4× |

TTA 只用于离线评估或疑难复核，不作为生产默认。

## 9. 训练与数据划分

### 9.1 按布料隔离

同一块布的 5 个视角必须进入同一 split，否则测试集会泄漏。

```text
fabric_id = 去掉末尾两位视角编号
例如 d10_01.jpg -> d10
```

### 9.2 去重

构建前对图像做 MD5，字节级重复只保留一份；`data_other/train` 与 `test` 相同，只使用一份。

### 9.3 训练增强

```text
Resize(1.04×)
RandomResizedCrop(scale 0.6~1.0)
随机正交旋转 0/90/180/270
水平翻转、垂直翻转
随机灰度 p=0.2
亮度/对比度扰动 0.15
```

验证和盲测不做增强。

### 9.4 损失

棉含量：

```text
L = alpha * CE + (1-alpha) * KL(student/T || teacher/T) * T^2
```

默认 `alpha=0.3`、`T=4`。教师权重缺失时退化为 `L = CE`。

## 10. 评估指标

```text
Top-1 = 对角线和 / 总数
Recall_i = 第 i 类正确数 / 第 i 类总数
整布表决 = 同一布料多视角概率取平均后 argmax 是否正确
```

固定盲测：16 块布、80 张图。样本量小，指标存在统计噪声。

## 11. 复杂度与部署

- 单帧预处理 O(H×W)
- 纯面料推理约 0.67 GFLOPs
- 棉含量推理约 14.6 GFLOPs
- 树莓派 4B 单帧总延迟约 1~3 秒（取决于线程和散热）
- 门控跳过棉含量模型时，平均延迟显著下降

## 12. 失效模式

1. 失焦或照明不足：清晰度下降，应强制复核。
2. 镜头倍率变化：ROI 与训练视野不一致，精度下降。
3. 布料颜色/组织差异大：可能超出训练分布。
4. 纯面料模型误判导致门控跳过：演示时可设 `cotton_gate=0` 强制两模型都运行。
5. 低棉/混纺与高棉边界重叠：会出现“待定”，属于预期行为。
