面料智能检测仪 —— 说明


一、它是用来做什么的
它被装在电熨斗里面。熨烫衣服之前，先用它"看一眼"这块面料是什么材质，
再根据材质把熨斗温度调到合适的档位——这样既能把衣服熨平，又不容易把衣服烫坏、烫黄、烫亮。

二、为什么熨烫前要先看材质（跟温度的关系）
不同面料能承受的温度差别很大：
温度调对了，熨烫才安全、效果也好。


三、它是怎么工作的（简单说，就四步）
    第 1 步  放大拍照
             把面料放到镜头下面，设备自动拍下放大的画面。

    第 2 步  自动分析
             设备里的程序会自动分析这张画面。

    第 3 步  两步判断
             先看它属于哪一类面料：
                棉 / 羊毛 / 涤纶 / 丝 / 亚麻 / 其他；
             如果判断可能含棉，再看含棉量的高低：
                低棉 / 中棉 / 高棉。
             （不是棉的，就不做第二步，直接出结果，这样又快又省电。）

    第 4 步  出结果
             分析完，用"灯"告诉您结果，
             您再据此把熨斗温度调到合适的档位。

四、算法说明：它为什么能认出来？
    一句话：因为它"见过"很多很多面料，所以认得出来。

    · 出厂前，我们让它在电脑上"看"了大量各种面料的放大照片，
      它就像一位看多了面料的老裁缝，慢慢记住了每一种面料放大后的"纹理长相"。

    · 检测时，它把刚拍到的画面，和自己记住的各种面料逐一比对，
      找出"最像哪一类"，同时给出"有几分把握"。

    · 所以它不是死记某一张照片，而是看"整体的特征"——
      同一类面料，就算颜色不同、摆放方向不同，也基本能认出来。

    · 为了又快又准，它分两步走：先大致判断"是不是棉"；
      如果是棉，再细看"含棉量大概多少"。不是棉的就不做第二步，省时省电。

   
五、三颗指示灯怎么读
机器上有三颗小灯，从左到右依次是：第 1 颗、第 2 颗、第 3 颗。

    ● 开机 / 待命：走马灯
      三颗灯会一颗接一颗地轮流亮
      （第 1 颗 → 第 2 颗 → 第 3 颗 → 第 2 颗 → ……，像跑马灯一样来回转）。
      看到它转，就表示：设备已经准备好，可以开始检测了。

    ● 检测结果：只亮一颗
      每次检测完成后，只亮其中一颗灯，代表这次的结果：

          亮第 1 颗  →  第 1 档  →  其他
          亮第 2 颗  →  第 2 档  →  羊毛 / 涤纶 / 低棉
          亮第 3 颗  →  第 3 档  →  棉

      
    ● 异常：三颗一起闪
      如果三颗灯同时快速闪 3 下，说明设备可能出了问题，比如摄像头没插。
     

六、操作步骤
    1. 通电开机后，大概需要三分钟，等灯开始"走马灯"（表示已经准备好）；
    2. 把面料样品放好，对准镜头；
    3. 按机器上的按钮；
    4. 稍等 1~2 秒，看灯读取结果；
    5. 根据结果把熨斗温度调到合适档位，再开始熨烫。
