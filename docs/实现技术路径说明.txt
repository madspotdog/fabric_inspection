面料智能检测仪 —— 实现技术路径说明
====================================================================
（面向客户/领导讲解用，简明版）

一、系统概述
本设备利用"显微成像 + 双 AI 模型"自动判定面料类别与棉含量档位，
整机在树莓派上离线运行，无需联网、无需上传图片，单次检测约 1～2 秒，
结果通过指示灯与屏幕界面同时输出。

二、硬件平台
- 主控：树莓派 Raspberry Pi 4B（2GB 内存），嵌入式 Linux 系统；
- 成像：USB 数字显微镜（ST-301-5M 等），1280×720、MJPG 格式；
- 交互：三色指示灯（档位指示）+ 拍照按钮 + 全屏显示界面；
- 全部本地运行，数据不出设备。

三、技术路径（总体流程）
    图像采集 → 图像预处理 → 双模型推理 → 级联门控 → 决策融合 → 结果输出

    1. 图像采集
       通过标准摄像头驱动直接从 USB 显微镜取流（1280×720），
       保证画面清晰、流畅。

    2. 图像预处理
       对画面做"中心正方形裁剪"，再缩放到模型输入尺寸，
       并做标准归一化处理，使输入与模型训练时的数据分布一致。

    3. 双模型推理（核心）
       同时部署两个轻量级深度神经网络分类模型：

       • 模型 A —— 面料类别识别
         识别面料种类：棉 / 羊毛 / 涤纶 / 丝 / 亚麻 / 其他。

       • 模型 B —— 棉含量档位识别
         判定棉含量档位：低棉 / 中棉 / 高棉。

       两个模型各司其职、独立输出，互为补充。

    4. 级联门控（Cascade Gating，省算力的关键）
       先运行"面料类别模型"：
         - 只有判定为"可能含棉"时，才继续运行"棉含量档位模型"；
         - 否则跳过，直接按面料类别出结果。
       这样在保证精度的同时，大幅减少不必要的计算，适配树莓派的算力。

    5. 决策融合（置信度阈值 + 业务映射）
       - 对模型给出的概率做置信度判断，低于阈值的结果归为"待定/其他"；
       - 结合两个模型的结果做交叉校验，输出最终判定。

    6. 结果输出
       把最终结果映射为"判定档位（第 1 / 2 / 3 档）"，同步输出到：
         - 三色指示灯（只亮对应的一颗灯）；
         - 全屏界面（显示"判定档位 第 N 档"）；
         - 后台日志（保留完整结果，便于后续标定）。

四、工程与优化要点
- 推理加速：采用面向嵌入式设备的推理引擎，让模型在树莓派上流畅运行；
- 算力优化：两个模型顺序执行、合理分配线程，避免互相抢占；
- 精度增强：采用多角度增强的平均策略，提升检测稳定性；
- 内存适配：模型均为轻量级网络，2GB 内存可稳定运行；
- 完全离线：模型与推理均在本机完成，无云端依赖。

五、判定结果对照表
    亮的灯        档位        含义
    第 1 颗       第 1 档     其他
    第 2 颗       第 2 档     羊毛 / 涤纶 / 低棉
    第 3 颗       第 3 档     棉

    待机（未检测）：三颗灯"走马灯"式循环流动，表示设备就绪；
    异常：三颗灯同时快速闪 3 次。

六、技术亮点小结
1. 双模型分工：一个负责"是什么面料"，一个负责"棉含量多少"，各司其职；
2. 级联门控：先粗判再精判，算力用在刀刃上；
3. 轻量模型 + 嵌入式推理加速，实现边缘端近似实时检测；
4. 完全离线、本地运行，隐私安全、响应快、不依赖网络。
