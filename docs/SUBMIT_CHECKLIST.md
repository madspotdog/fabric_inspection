## 二、你还要做的事

- [ ] **确定软件全称与版本**（当前：`纯面料及混纺双模型智能识别软件 V1.0.0`），
      申请表、源代码页眉、说明书封面三处保持一致。
- [ ] **确定著作权人**：个人（身份证）或公司（营业执照）。
- [ ] **补 6 张截图**，插入 `软件说明书.docx`（当前为占位）：
      1. 主界面空闲（三灯走马灯）；2. 结果第 1 档；3. 结果第 2/3 档；
      4. 模型自检终端；5. CSV 台账；6. 安装/启动命令。
- [ ] **确认开发完成日期、首次发表日期**（未发表可写"未发表"）。
- [ ] **确认权属**：如为公司职务作品，附职务作品声明/劳动合同。
- [ ] **复核 `源程序.docx`**：确认无密码、内网 IP、个人邮箱、客户数据。
- [ ] **导出 PDF**：提交一般用 PDF，Word 另存为 PDF 即可。

## 三、注意事项

1. **页数**：当前 49 页 < 60，按规则**提交全部**；不要硬凑。
2. **页眉/页码**：必须体现软件名+版本；docx 已设置，提交前再核对一遍。
3. **不要提交模型 `.bin`**（是数据，不是源码）。
4. **第三方组件**：`train_dual_yolo.py` 依赖 Ultralytics（AGPL），
   说明书表述为"底层分类网络采用开源模型微调"，不要写成完全自研。
   如需更干净，可从软著源码中剔除该训练脚本。
5. **敏感信息**：不要出现密码、密钥、Token、内网 IP、个人邮箱、客户数据。
6. **一致性**：申请表、代码、说明书里的软件名/版本必须完全一致。
7. **留档**：记录提交时的 Git 提交号与模型哈希；导出源码压缩包并保存校验值。
8. **版本演进**：若最终交付版与本次提交差异较大，建议另登记最终版本。

## 四、提交步骤（中国版权保护中心）

1. 打开官网：`https://www.ccopyright.com.cn`（中国版权保护中心），
   选择"软件著作权登记"。
2. **注册并实名认证**账号（个人或单位）。
3. **在线填写申请表**：
   - 软件全称、简称、版本号；
   - 开发完成日期、首次发表日期；
   - 开发方式（独立/合作/委托/职务）、权利取得方式（原始/继受）；
   - 著作权人信息、联系人。
4. **上传/邮寄鉴别材料**：
   - 源程序：`源程序.docx`（转 PDF）；
   - 说明书：`软件说明书.docx`（转 PDF）；
   - 身份证明（身份证/营业执照）；
   - 权属证明（如职务作品声明、委托开发合同）。
5. **提交并缴费**（官方登记通常不收费，加急另计）。
6. **受理 → 审查 → 发证**，下载电子证书。

## 五、时间与费用
