树莓派需要执行：

记录平均、最大耗时和温度。

## 7. 已知限制

1. 盲测样本仅 16 块布，统计噪声大。
2. 纯面料 100% 不是独立盲测。
3. 现场相机、倍率、照明变化会改变分布。
4. 级联门控可能因纯面料误判而跳过棉含量模型。
5. 交叉校验不能判断哪个模型正确，只能标记不一致。
6. 32 位 ARM 的 NCNN 性能需要在目标板实测。
7. 长时间连续运行的温升和内存未做压力测试。

## 8. 测试结论

- 软件功能链路完整：图像输入、双模型推理、交叉校验、界面显示、台账归档。
- 单元测试和模型校验通过。
- 固定盲测达到当前数据条件下的预期水平。
- 现场验收仍需使用未参与训练的真实布料、目标相机和目标开发板复测。
