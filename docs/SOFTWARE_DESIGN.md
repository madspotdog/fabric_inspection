# 软件设计说明书

软件名称：面料显微图像双模型智能识别软件  
版本：V1.0.0  
文档类型：软件设计说明书

## 1. 引言

### 1.1 编写目的

说明软件的总体结构、模块划分、数据接口、算法流程、异常处理和部署方式，作为开发、测试、维护和软件著作权登记的技术依据。

### 1.2 适用范围

适用于 USB 显微镜采集的面料显微图像离线识别，可在树莓派 4B（32/64 位）或其他具备 Python 与 NCNN 的 Linux 边缘设备运行。

### 1.3 术语

| 术语 | 说明 |
|---|---|
| ROI | 感兴趣区域，本软件指中心 660×660 正方形 |
| NCNN | 面向移动/边缘设备的神经网络推理框架 |
| TTA | 测试时增强，本软件指多角度推理后取平均 |
| 门控 | 用纯面料模型的 P(棉) 决定是否运行棉含量模型 |
| 复核 | 两个模型结果不一致、置信度不足或图像质量不足 |

## 2. 总体设计

### 2.1 设计原则

1. 离线优先：不依赖公网和云端。
2. 双模型独立：两个模型各自输出，避免单模型误差累积。
3. 可解释：保留原始类别、业务类别、概率和阈值。
4. 可配置：阈值、输入尺寸、线程数均可通过参数调整。
5. 可追溯：每次检测可写入 CSV 台账并保存原始 ROI。

### 2.2 体系结构

```text
┌──────────────────────────────────────────┐
│ 采集层：USB 显微镜 / 图片文件              │
└──────────────────┬───────────────────────┘
                   ↓
┌──────────────────────────────────────────┐
│ 预处理层：中心 ROI、缩放、归一化、清晰度    │
└──────────────────┬───────────────────────┘
                   ↓
┌──────────────────────────────────────────┐
│ 推理层：纯面料模型（门控） → 棉含量模型     │
└──────────────────┬───────────────────────┘
                   ↓
┌──────────────────────────────────────────┐
│ 决策层：阈值、交叉校验、待定/复核           │
└──────────────────┬───────────────────────┘
                   ↓
┌──────────────────────────────────────────┐
│ 展示与归档：窗口、终端、CSV、样图           │
└──────────────────────────────────────────┘
```

### 2.3 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Raspberry Pi OS 32/64 位或其他 Linux |
| Python | 3.9 及以上 |
| 依赖 | ncnn、numpy、Pillow、opencv |
| 内存 | 建议 1 GB 以上 |
| 相机 | UVC 免驱 USB 显微镜，建议 1280×720 MJPG |
| 模型 | 两个 NCNN 模型，输入 in0、输出 out0 |

## 3. 模块设计

### 3.1 采集模块

- 摄像头：`cv2.VideoCapture`，可配置设备号、分辨率、MJPG。
- 图片：支持 jpg/jpeg/png/bmp。
- 目录：批量读取并逐张识别。

### 3.2 预处理模块

| 函数 | 功能 |
|---|---|
| `center_square` | 取中心正方形 ROI |
| `resize_square` | 缩放到模型输入尺寸 |
| `to_float_rgb` | BGR→RGB、uint8→float |
| `imagenet_normalize` | ImageNet 均值方差归一化 |
| `plain_normalize` | 0~1 归一化 |
| `focus_score` | 拉普拉斯方差清晰度 |

### 3.3 推理模块

`NcnnModel` 封装：

- 加载 `.param` 与 `.bin`
- 设置线程数、FP16、packing layout
- 输入 `in0`，输出 `out0`
- 返回概率向量
- 可选四向 TTA

`InspectionPipeline` 负责：

- 先运行纯面料模型
- 读取 P(棉)
- 达到门限再运行棉含量模型
- 调用决策模块

### 3.4 决策模块

`decide()` 输入：

```text
cotton_probs     三分类概率或 None
fiber_probs      六分类概率
fiber_names      类别顺序
thresholds       阈值集合
focus            清晰度
```

输出 `InspectionResult`，包含：

```text
cotton_tier, cotton_raw, cotton_confidence, cotton_margin
cotton_probabilities, cotton_gate_probability, cotton_entered
pure_fiber, fiber_raw, fiber_confidence, fiber_probabilities
cross_check, focus, thresholds
```

### 3.5 归档模块

`RecordWriter`：

- CSV 使用 UTF-8 BOM，Excel 可直接打开
- 编号从已有台账续接
- 支持保存 JPEG 样图
- CSV 写入失败时回滚已写图片和追加内容
- 列结构不兼容时拒绝写入，避免破坏旧数据

### 3.6 展示模块

树莓派包使用 OpenCV 窗口 + PIL 中文字体：

- 右侧深色面板
- 大字显示棉含量、纯面料、最终判定
- 显示两路置信度、门控概率、清晰度、推理时间
- 绿色“通过”、橙色“复核”

## 4. 数据设计

### 4.1 模型输出

```text
棉含量：["Tier0_Low", "Tier1_Mid", "Tier2_High"]
纯面料：["丝", "亚麻", "其他", "棉", "涤纶", "羊毛"]
```

### 4.2 结果结构

见 `src/fabric_inspection/decision.py` 中的 `InspectionResult`。

### 4.3 台账字段

```text
检测时间, 样品编号, 棉含量档位, 纯面料结果, 交叉结论,
棉含量置信度, 纯面料置信度, 棉门控概率, 清晰度, 存样图
```

## 5. 接口设计

### 5.1 命令行参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `--camera` | 摄像头编号 | 无 |
| `--image` | 单张图片 | 无 |
| `--dir` | 图片目录 | 无 |
| `--threads` | NCNN 线程数 | 2 |
| `--cotton-imgsz` | 棉含量输入 | 384 |
| `--fiber-imgsz` | 纯面料输入 | 288 |
| `--cotton-gate` | P(棉) 门限 | 0.20 |
| `--cotton-threshold` | 棉含量置信度 | 0.46/0.55 |
| `--cotton-margin` | 棉含量边界差 | 0/0.10 |
| `--fiber-threshold` | 纯面料置信度 | 0.50 |
| `--focus-threshold` | 清晰度阈值 | 75 |
| `--no-fp16` | 关闭 FP16 | 关 |
| `--mjpg` | 请求相机 MJPG | 关 |

### 5.2 模型文件接口

```text
model.ncnn.param  结构
model.ncnn.bin    权重
labels.json       类别顺序
```

输入节点 `in0`，输出节点 `out0`。

## 6. 异常处理

| 异常 | 处理 |
|---|---|
| 模型加载失败 | 终止并提示文件路径 |
| 推理返回非零 | 抛出异常并终止当前检测 |
| 摄像头打不开 | 提示设备号并退出 |
| 图像读取失败 | 跳过该图并提示 |
| CSV 列结构不兼容 | 拒绝写入，要求使用新目录 |
| CSV 写入失败 | 回滚图片和追加内容 |
| 置信度不足 | 输出待定/复核，不强行分类 |
| 失焦 | 输出复核 |

## 7. 性能设计

- 两个模型顺序执行，避免线程池争抢 CPU。
- 门控跳过棉含量模型可降低平均延迟。
- 默认关闭 TTA。
- 支持 2/3/4 线程实测选择。
- 32 位 ARM 默认关闭 FP16，避免无硬件支持时变慢。

## 8. 安全与合规

- 完全离线运行，不上传图像。
- 台账和样图保存在本地。
- 模型文件使用 SHA256 清单校验。
- 第三方组件许可证见 `THIRD_PARTY.md`。
- YOLOv8 使用 AGPL-3.0，商业分发前必须确认授权方式。

## 9. 部署与维护

- 64 位包：`packages/64bit`
- 32 位包：`packages/32bit`
- 安装：`setup_pi.sh`
- 自检：`--check`
- 性能：`benchmark_dual.py`
- 模型校验：`tools/verify_models.py`
- 换平台：保持 `in0/out0` 和类别顺序，替换推理后端即可。
